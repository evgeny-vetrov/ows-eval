# Фабула для пользователя

Как продукт выглядит для пользователя, до того как появится веб-морда.
- **Подход prompt-first.** Промт — главный объект. Правят в одном виде за раз — в промте, графе или OWS, остальные подтягиваются сами. Экран «Посмотреть изменения» показывает дифф всех трёх.
- **Персоны и CJM** — четыре персоны и путь каждой.
- **Разделы интерфейса** — функции каждого раздела и привязка к операциям API.
- **Макеты** всех основных экранов.

## Прототип

```
cd ai/gena/services/fabula/product/prototype
npm ci
npm run dev      # http://localhost:5173 — на главной список экранов
```

Что в прототипе живое:
- **кнопки ведут по пути персон**: «+ Новый сценарий» → «Собрать» → редактор с вопросом под промтом → «Посмотреть изменения» → «К публикации» → «Сохранить и запустить» → миграция → входящие. Второй путь — «Запустить эксперимент» → выкатка → «Запустить на 100 %» → миграция. «Сценарии» → строка → редактор; крошки ведут наверх. Действия без своего экрана показывают подтверждение внизу;
- **экран 2** — редактор нового сценария: промт и вопрос слева, граф справа. Наведение на варианты ответа перестраивает граф, переключатель «Граф | OWS» показывает тот же ответ кодом. «Ответить» дописывает ответ в пункт 5 и ставит граф на выбранный вариант;
- **экраны 3 и 4** — переключатель «Промт | Граф | OWS» ведёт на три режима редактора; в режиме «Промт» граф стоит рядом и переходом показывает правку;
- **экраны 5 и 6** — дифф открывается переходом от старой версии к новой, кнопки «Было / Стало» («До правки / После правки») повторяют его; на экране 5 переключатель «Граф | Промт | OWS»;
- **экран 5** — карточка «Проверка поведения»: что нашла проверка под капотом, с подсветкой на графе;
- **экран 7** — три кнопки: «Сохранить и запустить», «Запустить эксперимент» (диалог с долей новых стартов, до 50 %) и «Сохранить».

Остальные экраны статичны.

Как переснять картинки:
- все сразу: `npm run build && npm run shoot`;
- один снимок: `npm run shoot -- 05-changes-graph`.

Съёмка идёт в Chromium из `/opt/pw-browsers` (другой браузер — через переменную `CHROME`). Результат пишется в `../images` (другой каталог — через `OUT`). Анимации собираются в GIF из кадров, для кадров морфинг замораживается через `window.__freeze`.

## Устройство

- **`src/graph/`** — граф процесса:
  - `types.ts`, `data.ts` — модель и данные сквозного примера `gena/ticket-to-prod` версий 1.0.0 и 1.1.0;
  - `diff.ts` — дифф двух версий: новые, уходящие, изменённые и переименованные узлы и рёбра;
  - `layout.ts` — раскладка «хребта»: ряды по самому длинному пути, боковые узлы — в дорожках;
  - `ProcessGraph.tsx` — узлы и рёбра React Flow: тип шага (агент, человек, MCP, HTTP, Нирвана), стили диффа и слои «идущие запуски», «пройдено», «сейчас»;
  - `Morph.tsx` — переход между графами в три такта: ушедшее гаснет, общее сдвигается, новое проявляется; может сыграть переход сам при открытии экрана.
- **`src/screens/`** — 13 экранов дока, среди них список сценариев, редактор в режимах «Граф», «OWS» и «Промт» с графом рядом, экран изменений, публикация и выкатка — страница сценария без вкладок.
- **`src/diagrams/`** — схемы.
- **`scripts/shoot.mjs`** — съёмка.

Это макет, а не начало веб-морды. Переносить стоит компоненты графа (`ProcessGraph`, `diffGraphs`, `Morph`, `spineLayout`); экраны написаны под картинки.
